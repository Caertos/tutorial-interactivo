import { sum } from "example";
  • import

    Palabra clave de JavaScript que trae código de otro módulo a tu archivo.

  • { sum }

    El nombre exacto de la función. Las llaves indican una exportación con nombre: escríbelo igual, respetando minúsculas.

  • from "example"

    El paquete de donde sale. Debe estar instalado antes: npm install example.
